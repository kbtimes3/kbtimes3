Currently a postdoc at SUBATECH in Nantes, France.

# Projects

## Research projects

- [AutoTherm](https://autotherm.in2p3.fr/): a new tool to automatically compute thermal production/interaction rates, from a user-given Lagrangian.
    - Developped by Jacopo Ghiglieri, Greg Jackson and myself.

## Small projects

- [minifeyn](https://github.com/kbtimes3/minifeyn): a LaTeX package to draw Feynman diagrams in equations.
- [nice-export](https://github.com/kbtimes3/nice-export): a collection of scripts to export numerical data along with
information about the program used to create it, the export date, *etc.*
    - Currently only in Python and Mathematica.
